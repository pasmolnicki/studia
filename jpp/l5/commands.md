## Haskell

Run with:
```sh
ghci haskel.hs
```

Or just:
```sh
ghc -e "binomial2 30 15" haskel.hs
```

Inside:

```sh
:set +s
binomial 22 10
binomial2 22 10
mergesort [5, 2, 9, 1, 5]
de 101 13
prime_factors 315
totient 5000
totient2 5000
primes 30
:q
```

## Ocaml

Run with:
```sh
ocaml
```

Inside:
```sh
#use "ocaml.ml";;
#time true;;
binomial 22 10;;
binomial2 22 10;;
mergesort [5; 2; 9; 1; 5; 6];;
de 101 13;;
prime_factors 315;;
totient 4000;;
totient 4000;;
primes 30;;
```
